# Complete MERN Portfolio Application

## Features
- ✅ Full MERN Stack (MongoDB, Express, React-like, Node.js)
- ✅ Data stored in MongoDB (not localStorage)
- ✅ Admin panel with JWT authentication
- ✅ CRUD operations for Profile, Skills, Projects, Achievements, Certificates
- ✅ EmailJS contact form
- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Particle effects, animations, and modern UI

## Installation

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (local or Atlas)
- Git

### Step 1: Clone and Install
```bash
git clone <your-repo-url>
cd portfolio-mern
npm run install-all
